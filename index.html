EduBot · online AI learning demo

FastAPI · Docker · Cloudflare Tunnel · local models only
A learning tool for Python beginners. The question behind it: can small local models handle chat, quizzes, encouragement, and sandboxed code with no cloud API?
  • Moved orchestration from n8n to FastAPI: memory went from ~512MB to ~80MB, cold start under a second
  • Three-layer topic gate (fast rules, the fine-tuned model, keyword fallback) filters each message; a router then picks 0.8B, 4B, or 9B by difficulty
  • Live behind TLS and access control as a demo; no formal users yet

QJev 3.5-0.8B · fine-tuned decision engine (Apache-2.0)

Hugging Face · released with training and evaluation sets
94.4% routing accuracy on a 180-item set (prompt baseline 27.2%, official same-set 91.7%).
  • A next-generation gate model that grew out of EduBot's needs: reads a state, a question, and the options, then returns a probability for each option in one forward pass. Live in the EduBot gate since 2026-11-01 with primary/backup failover; released with its training and evaluation sets

Ninfer · ternary engine ports: RTX 30 (sm_86) and AMD ROCm (gfx1100)

personal projects, open source · upstream engine: ninfer-all
Both ports started from one question: can a 27B ternary model run on a 12GB consumer card, and how fast?
  • RTX 30 port: after fixing a parsing bug that had silently disabled 60+ flags (including --spec), speculative decoding went from 1.00 to 4.85 tokens per round and English decoding from 73.8 to 198.8 t/s
  • ROCm port (research, now frozen): a HIP shim brings the engine to an RX 7900 XTX; hipGraph decoding reaches 45.8 t/s

SEHS4510 · touch-first data-science learning tool

final-year project · Blockly · FastAPI · Docker
Block-based data-science tools are built for a mouse and work poorly on tablets; this final-year project rebuilt the interaction for touch.
  • Within-subjects pilot: three participants (all from IT backgrounds, a deviation from the planned non-IT audience, recorded in the report) finished tasks faster on the prototype and said it was easier to start with; the findings became six design guidelines
  • Its sandboxed execution service, shared with EduBot, later went through a security audit. All 16 findings were fixed (import allowlist, fail-closed token auth, per-IP rate limiting), each with a regression test.
